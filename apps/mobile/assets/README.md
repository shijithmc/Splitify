# Illustrated design assets

The `illustrations/together.png` and `illustrations/scan.png` assets were generated for the user-approved Hisaab mockup design on 27 September 2026 using OpenAI's built-in image generation tool. They are bundled locally; the app does not fetch illustration assets at runtime.

Outfit headings and Work Sans body fonts come from Google Fonts. The original SIL Open Font License notices are included in `fonts/Outfit-OFL.txt` and `fonts/WorkSans-OFL.txt`. Font families and supported weights are declared in `pubspec.yaml`.

Palette and component defaults live in `lib/core/design.dart`. Small group scenes are native decorative vector drawings in `lib/features/shared.dart`.
