# ADR 0001: v1 defaults

Accepted for implementation following the user's “do it” instruction on 26 September 2026. Use Flutter, .NET 10 ARM64, DynamoDB, CDK C#, RevenueCat account entitlement, INR and annual ad removal. Apply the implementation plan's recommended identity, retained-member, dispute and rounding policies. Banners first; interstitials disabled. No live cloud deployment or store product creation in this source implementation task.

The group cap counts 50 retained ledger identities. Percentages use 0–10,000 basis points; zero allocations receive no remainder. Shares are 1–10,000. A disputed payment reverses once. Creator may record for placeholders/deleted members; a newly claimed receiver may dispute earlier payments. Active participants may change expenses they were involved in. Archived groups are read-only. Group deletion is soft and requires no outstanding direct debts. Expense cap is 10,000 allocated IDs including tombstones.

Identity linking requires proof of both credentials. Typed phone numbers never authorize claims. Apple Android web flow is included when configured. Provider credentials, merchant/store approvals and privacy-policy sign-off remain external release prerequisites. Local demo mode must be visibly separate from production; absent production configuration must fail closed.
