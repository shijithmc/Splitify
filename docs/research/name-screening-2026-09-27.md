# Replacement name shortlist — 27 September 2026

**Recommendation: take Milhissa into the final name check and a small pronunciation test.** Alternatives: Saathsum, Bantilo, Hissivo and Jodsum. These are five *preliminarily screened candidates*, not approved trademarks or reserved store names. No rebrand, domain purchase, account creation or trademark filing was performed.

The screen found no matching app title for these five in the checks below. It did find direct competitors using **Hisaab** and **Splitify**, so neither should become the public launch name.

## What was actually checked

All checks below were run on **2026-09-27 (Asia/Kolkata)**.

1. Exact quoted names in a web search constrained to the primary store domains `play.google.com` and `apps.apple.com`.
2. Exact quoted names in broader web searches, then searches with app, finance, payment, company and business terms. This checks indexed use, not corporate-register completeness.
3. Apple's public software search API for **India and the United States**, with `media=software`, `entity=software`, `limit=200`. Returned app names were inspected; broad/fuzzy suggestions were not treated as exact-name matches.
4. A small set of obvious spelling variants. This is not a comprehensive phonetic or transliteration search.
5. Both search portals linked by IP India's official “Search Existing Trademarks” page. Neither yielded registry results without authentication/CAPTCHA steps; no clearance claim follows from visiting the portals.

**Limits:** The live Google Play search pages were unavailable through the web reader. Thus the Google Play result is an **indexed-listing screen**, not a verified native Play India catalog search. Store indexing and Apple search results can omit apps, and a name can be reserved without appearing publicly. Domains and social handles were not checked for registration availability. No Indian trademark register search was completed. No negative search proves that a name is available to use.

## Trademark status and completion gate

**All five: unverified in the Indian trademark register.** The official [IP India entry page](https://ipindia.gov.in/trade-marks-before-you-apply-search-existing-trademarks) links two portals:

- [Legacy public search](https://tmrsearch.ipindia.gov.in/tmrpublicsearch/) displayed email/mobile, CAPTCHA, Send OTP and Verify fields. No search was submitted and no CAPTCHA was solved.
- [AI/ML search](https://tmsearch.ipindia.gov.in/ords/r/tisa/trademark_search600/login) displayed email/mobile and password sign-in, sign-up and OTP fields. No account was created or used.

The older deep URL ending in `frmmain.aspx` failed in the reader/browser; following IP India's current link exposed the OTP/CAPTCHA form above. This is an access limitation, not a clean registry result. IP India's [filing guidance](https://ipindia.gov.in/application-workflow/trademark-filing-process) specifically calls for checking existing marks, assessing similarity/conflicts and selecting the correct classes.

Before the actual rebrand:

1. Select a preferred candidate and one fallback. Run a brief “hear it, spell it, say what it suggests” test with users across the launch languages; do not assume Hindi familiarity across India.
2. Complete an authenticated Indian wordmark and phonetic search for exact names, stems, misspellings and transliterations. Have qualified trademark counsel assess the findings and applicable classes; downloadable software and hosted software are starting areas, with finance-related services reviewed against the actual product. No legal availability conclusion is made here.
3. Check the final names in the native Play India and App Store India search interfaces and in the publishing consoles. Check intended domains and social handles at selection time, and reserve only after authorization.
4. Record the selected spelling, pronunciation and approved descriptor, then implement a rebrand migration that preserves accounts, data, purchases and existing installations. Do not mechanically rename purchase or package identifiers.

Passing these steps is the branding gate. It does not block planning or building features under the current internal project name.
